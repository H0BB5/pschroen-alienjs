# aliencn

Source-first React components for dashboards, Space.js interactions, and Alien.js WebGL experiences.

```sh
npx aliencn init --yes
npx aliencn add button card panel
```

The package exposes both `aliencn` and `alien` binaries and a typed library API. It detects Next.js, Vite React, TypeScript/JavaScript, aliases, and npm/pnpm/Yarn/Bun; performs safe idempotent writes; and keeps official `@alienkitty` packages as the runtime source of truth.

Full documentation, architecture, and the component catalog are in the [GitHub repository](https://github.com/H0BB5/pschroen-alienjs).
